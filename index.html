Moni

A desktop app for making short videos.

Moni is a Windows/macOS/Linux desktop application that helps creators turn a topic into a finished short video: it writes a script, generates scenes and a voiceover, adds captions, and assembles the final file on the user's own computer.

After the user connects their own account, Moni can upload the finished video to TikTok on the user's behalf, using TikTok's official Content Posting API. Videos are only posted when the user starts an upload.
